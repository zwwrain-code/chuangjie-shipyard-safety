# 创界 · 船厂人员位置与安全报警

创界（南通）智能科技有限公司的 GitHub Pages 方案站。静态 HTML / CSS / JS，正文为中文。

页面按解决方案的顺序阅读，不从公司口号起笔：

1. 首屏：产品名称，以及险情之后要看清位置并留下记录
2. 系统组成：定位标签、现场基站、船厂位置图、报警状态
3. 人员位置：图上可见、办公楼与船坞同一标识、试点中的单位区分、钢结构旁的覆盖要现场调整
4. 安全报警：圈出范围、列出附近的人、疏散时人工确认、留下记录
5. 怎么落地：不替换消防、对接定位厂商、先做一个船位，以及四项验收
6. 试点讨论

## 口径

- 平台只接收报警状态，不向消防设备下发控制指令。
- 本厂、协作单位和访客的同屏区分，写成试点配置，不写成已经交付的部署。
- 钢结构与舱室的覆盖要现场调整和实测，测不到的区段标成未覆盖。
- 不写定位精度数字。误差以试点实测为准。
- 照片、平面图和名单均为示意，人员点位为模拟数据。
- 页面不放电话、邮箱、即时通讯账号或地址。

本地预览：在仓库根目录执行 `python3 -m http.server`，用手机宽度（320、390）和桌面宽度打开。页面不依赖外部字体、脚本或地图服务。
